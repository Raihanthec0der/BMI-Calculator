⚖️ BMI Calculator — Your Health, Your Journey
A simple Python-based BMI Calculator that calculates Body Mass Index from a user's weight and height and provides a BMI category along with an encouraging motivational message.

🌟 Features
⚖️ Calculates BMI using weight and height
📏 Accepts height in feet and inches
🔢 Converts height into meters automatically
📊 Classifies BMI into four categories
💬 Provides motivational messages for each category
😊 Uses emojis to make the program more friendly
🌱 Encourages healthy habits and continuous improvement
🧮 How It Works
The program asks the user for:

Weight in kilograms
Height in feet
Height in inches
It then converts the height into meters and calculates BMI.

BMI = Weight (kg) / Height² (m)
The program then determines whether the BMI falls into:

BMI	Category
Below 18.5	🪶 Underweight
18.5 – 24.9	✅ Normal Weight
25 – 29.9	⚠️ Overweight
30+	🛑 Obesity
