# ⚖️ BMI Calculator — Your Health, Your Journey

A simple and beginner-friendly **Python BMI Calculator** that calculates Body Mass Index (BMI) based on a user's weight and height. It accepts height in **feet and inches**, converts it to meters, calculates BMI, and displays the corresponding BMI category with an encouraging motivational message.

---

## 🌟 Features

* ⚖️ Calculate BMI using weight and height
* 📏 Accept height in **feet and inches**
* 🔄 Automatically convert height into meters
* 📊 Classify BMI into four categories
* 💬 Display motivational messages for each category
* 😊 Friendly output with emojis
* 🌱 Encourage healthy habits and continuous improvement
* 🐍 Simple Python code suitable for beginners

---

## 🧮 How It Works

The program asks the user to enter:

1. Weight in kilograms
2. Height in feet
3. Height in inches

The height is then converted into meters, and BMI is calculated using the following formula:

```text
BMI = Weight (kg) / Height² (m)
```

### 📊 BMI Categories

| BMI Range   | Category        |
| ----------- | --------------- |
| Below 18.5  | 🪶 Underweight  |
| 18.5 – 24.9 | ✅ Normal Weight |
| 25 – 29.9   | ⚠️ Overweight   |
| 30+         | 🛑 Obesity      |
